## 📚 Detailed Learning Roadmap + Book Purposes

### **Phase 1 — Foundations: How Computers Work** (3–4 months)
**Start here first** — Everything else becomes much easier after this.

| Book | Purpose |
|------|--------|
| **Computer Systems: A Programmer's Perspective** | Understand CPU, memory, assembly, how code really runs on hardware |
| **The Linux Command Line** | Master terminal, file system, and Linux like a pro |
| **How Linux Works** | Deep understanding of operating system internals |
| **Computer Networking: A Top-Down Approach** | How the internet works (TCP/IP, HTTP, DNS, etc.) |
| **Pro Git** | Version control — essential skill |

**How to Read**: Read in order. Practice Linux commands daily.

---

### **Phase 2 — Java Language Core** (3–4 months)

| Book | Purpose |
|------|--------|
| **Java: A Beginner's Guide** | Learn Java syntax and basics from scratch |
| **Head First Java** | Deep understanding of OOP, objects, and Java thinking |
| **Effective Java (3rd Edition) - Joshua Bloch** | Write professional, idiomatic, bug-free Java code |
| **Grokking Algorithms** | Build strong algorithm thinking and problem-solving skills |

**How to Read**: Read Java books first, then solve 150–200 LeetCode problems while reading Grokking Algorithms.

---

### **Phase 3 — Professional Developer Skills** (2 months)

| Book | Purpose |
|------|--------|
| **The Pragmatic Programmer** | Learn how real professionals think and work |
| **Clean Code** | Write readable, maintainable code that others love |
| **Head First Design Patterns** | Master common design patterns (very useful in Spring) |
| **Refactoring - Martin Fowler** | Improve existing code quality |

**How to Read**: Apply concepts immediately while coding small projects.

---

### **Phase 4 — Backend & Database Mastery** (3–4 months)

| Book | Purpose |
|------|--------|
| **Spring Boot in Action** / **Spring in Action 5th** | Master the #1 Java backend framework |
| **Designing Data-Intensive Applications** | Understand real-world scalable backend systems |
| **Database Internals** | Deep knowledge of how databases work |
| **Learning SQL** | Master database querying |
| **Java Concurrency in Practice** | Multithreading, performance, and thread safety |
| **Spring Microservices in Action** | Build distributed systems |

**How to Read**: Build multiple Spring Boot projects (REST APIs, e-commerce, etc.) after each major topic.

---

### **Phase 5 — Frontend & DevOps** (3–4 months)

| Book | Purpose |
|------|--------|
| **JavaScript: The Good Parts** | JavaScript fundamentals |
| **You Don't Know JS (Kyle Simpson)** | Deep modern JavaScript knowledge |
| **React: Up & Running** | Build modern frontends for Java backends |
| **Docker Deep Dive** | Containerization — must-have DevOps skill |
| **Release It!** | Design production-ready, resilient applications |
| **Kubernetes in Action** | Orchestration and deployment at scale |

**How to Read**: Dockerize your Spring projects. Deploy them online.

---

### **Phase 6 — Architecture & System Design** (2–3 months)

| Book | Purpose |
|------|--------|
| **System Design Interview Vol 1 & 2** | Prepare for senior interviews & design large systems |
| **Fundamentals of Software Architecture** | Learn architectural thinking and trade-offs |
| **Domain-Driven Design - Eric Evans** | Design complex business applications |
| **Building Microservices - Sam Newman** | Real-world microservices best practices |

**How to Read**: Practice drawing system diagrams and explaining designs out loud.

---

## 🚀 Recommended Way to Study

1. Follow phases in strict order.
2. **After every phase** → Build 1–2 real projects.
3. Combine reading + coding daily.
4. Use LeetCode + GitHub for practice.
5. Deploy projects using Docker.
6. Review key books again after 6–12 months.
