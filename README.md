## 📚 The Full Roadmap

### Phase 1 — Foundations: How Computers Work
> ⏱️ `3–4 months` · **Start here — everything becomes easier after this.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **Computer Systems: A Programmer's Perspective** | CPU, memory, assembly — how code *really* runs on hardware |
| 2 | **The Linux Command Line** | Master terminal, file system, and Linux like a pro |
| 3 | **How Linux Works** | Deep understanding of OS internals |
| 4 | **Computer Networking: A Top-Down Approach** | TCP/IP, HTTP, DNS — how the internet actually works |
| 5 | **Pro Git** | Version control — a non-negotiable skill |

> 💡 **Study tip:** Read in order. Practice Linux commands every single day.

---

### Phase 2 — Java Language Core
> ⏱️ `3–4 months` · **Master the language before the framework.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **Java: A Beginner's Guide** | Java syntax and fundamentals from scratch |
| 2 | **Head First Java** | Deep OOP thinking, objects, and Java concepts |
| 3 | **Effective Java** — *Joshua Bloch* | Professional, idiomatic, bug-free Java code |
| 4 | **Grokking Algorithms** | Algorithm thinking and problem-solving skills |

> 💡 **Study tip:** Solve **150–200 LeetCode problems** while reading Grokking Algorithms.

---

### Phase 3 — Professional Developer Skills
> ⏱️ `2 months` · **Write code that teams love.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **The Pragmatic Programmer** | How real professionals think and work |
| 2 | **Clean Code** | Write readable, maintainable code |
| 3 | **Head First Design Patterns** | Common design patterns (essential for Spring) |
| 4 | **Refactoring** — *Martin Fowler* | Improve the quality of existing code |

> 💡 **Study tip:** Apply every concept immediately while building small projects.

---

### Phase 4 — Backend & Database Mastery
> ⏱️ `3–4 months` · **The core of your Java career.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **Spring Boot in Action** / **Spring in Action 5th** | The #1 Java backend framework |
| 2 | **Designing Data-Intensive Applications** | Real-world scalable backend systems |
| 3 | **Database Internals** | How databases work under the hood |
| 4 | **Learning SQL** | Master database querying |
| 5 | **Java Concurrency in Practice** | Multithreading, performance & thread safety |
| 6 | **Spring Microservices in Action** | Build distributed systems |

> 💡 **Study tip:** Build **multiple Spring Boot projects** — REST APIs, e-commerce backends, etc.

---

### Phase 5 — Frontend & DevOps
> ⏱️ `3–4 months` · **Deploy real products to the world.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **JavaScript: The Good Parts** | JavaScript core fundamentals |
| 2 | **You Don't Know JS** — *Kyle Simpson* | Deep modern JavaScript knowledge |
| 3 | **React: Up & Running** | Build modern UIs for your Java backends |
| 4 | **Docker Deep Dive** | Containerization — must-have DevOps skill |
| 5 | **Release It!** | Design production-ready, resilient apps |
| 6 | **Kubernetes in Action** | Orchestration and deployment at scale |

> 💡 **Study tip:** Dockerize every Spring project. **Deploy them online.**

---

### Phase 6 — Architecture & System Design
> ⏱️ `2–3 months` · **Think like a Senior Engineer.**

| # | 📖 Book | 🎯 What You'll Learn |
|---|---------|----------------------|
| 1 | **System Design Interview Vol 1 & 2** | Design large systems + crack senior interviews |
| 2 | **Fundamentals of Software Architecture** | Architectural thinking and trade-offs |
| 3 | **Domain-Driven Design** — *Eric Evans* | Design complex business applications |
| 4 | **Building Microservices** — *Sam Newman* | Real-world microservices best practices |

> 💡 **Study tip:** Practice drawing system diagrams and explaining designs **out loud**.
